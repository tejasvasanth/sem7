## Shared Contracts You Consume and Enrich

### Input — ContextState (from Desktop Agent / mock)
```typescript
{
  timestamp: number, idleTime: number, keyboardActive: boolean,
  mouseActive: boolean, wifiSSID: string, rssi: number,
  phoneMoving: boolean, battery: number, charging: boolean
}
```

### Output — ContextState (enriched, returned from /predict)
Same object, with these fields added:
```typescript
{
  confidence: number,          // 0–100
  decision: "LOCK" | "UNLOCK" | "WAIT",
  reason: string               // human-readable, e.g. "Phone moved away while idle for 42s"
}
```

### Robot telemetry you subscribe to (MQTT airlock/robot/status)
```typescript
interface RobotStatus {
  timestamp: number;
  state: "DOCKED" | "MOVING" | "GUARDING" | "CHARGING";
  batteryLevel: number;
  distanceToNearestObject: number;
  intruderDetected: boolean;
  photoUrl?: string;
}
```

## Decision Pipeline (runs on every /predict call)

```
Input: ContextState
         │
         ▼
  1. Rule Engine  ──────────────────────────────────────────────────────────────────
     if idleTime > 60 AND rssi < -75 → LOCK (confidence 95)
     if phoneMoving AND rssi < -70    → LOCK (confidence 85)
     if keyboardActive OR mouseActive → WAIT (confidence 90)
     else                             → WAIT (confidence 50) — pass to ML
         │
         ▼
  2. ML Engine (Random Forest)
     Features: idleTime, rssi, phoneMoving, keyboardActive, mouseActive, battery, charging
     Output: probability user has left (0.0 → 1.0)
     Scaled to confidence 0–100
         │
         ▼
  3. Confidence Blending
     blended = (rule_confidence * 0.4) + (ml_confidence * 0.6)
         │
         ▼
  4. Decision gate
     confidence >= 70  →  LOCK
     confidence <= 30  →  UNLOCK / WAIT
     40 < confidence < 60  →  pass to Gemini
         │
         ▼
  5. Gemini (only for uncertain band 40–60%)
     Prompt template:
       "Laptop idle {idleTime}s. RSSI {rssi}. Phone moving: {phoneMoving}.
        Mouse inactive: {not mouseActive}. Keyboard inactive: {not keyboardActive}.
        Recent user corrections: {adaptive_profile_summary}.
        Should the laptop lock? Respond with LOCK or WAIT and a one-sentence reason."
     Parse Gemini response → decision + reason
         │
         ▼
  6. Adaptive profile update
     Record decision + timestamp + context features in user_profile table
     After 50 decisions, retrain profile weights
         │
         ▼
  Return enriched ContextState
```

## FastAPI Endpoints

Base URL: `http://localhost:8000`

```
POST /predict
  Body:   ContextState (without confidence/decision/reason)
  Returns: ContextState (with confidence, decision, reason added)

POST /train
  Body:   { dataset_path?: string }  (optional; uses recorded history if omitted)
  Returns: { accuracy: number, featuresUsed: string[], trainedAt: number }

POST /correct
  Body:   { timestamp: number, correctDecision: "LOCK" | "UNLOCK" | "WAIT" }
  Saves a user correction for adaptive learning

GET /history?n=100
  Returns: last N prediction records from SQLite

GET /metrics
  Returns: { accuracy: number, falseLockRate: number, totalPredictions: number,
             modelTrainedAt: number, geminiCallsLast24h: number }
```

## SQLite Schema

```sql
CREATE TABLE predictions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  timestamp INTEGER NOT NULL,
  idle_time INTEGER,
  rssi INTEGER,
  phone_moving INTEGER,
  keyboard_active INTEGER,
  mouse_active INTEGER,
  battery INTEGER,
  charging INTEGER,
  rule_confidence REAL,
  ml_confidence REAL,
  blended_confidence REAL,
  decision TEXT,
  reason TEXT,
  gemini_used INTEGER DEFAULT 0
);

CREATE TABLE corrections (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  timestamp INTEGER NOT NULL,
  original_decision TEXT,
  correct_decision TEXT
);

CREATE TABLE model_metadata (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  trained_at INTEGER NOT NULL,
  accuracy REAL,
  features TEXT    -- JSON array of feature names
);
```

You can't train on real data day one. Ship a `generate_dataset.py` script that creates
1000 synthetic ContextState rows with realistic distributions:

- Idle time: normal distribution centered at 45s, σ=30
- RSSI: bimodal — "user present" cluster around -60, "user away" cluster around -85
- phoneMoving: correlated with rssi dropping
- Label: `user_left = 1` when rssi < -75 AND idleTime > 45 AND phoneMoving = True

Train the Random Forest on this. Replace with real data as it accumulates.
